QuLearn is a **solo project** designed to help students learn smarter.  
It is an **AI-powered tutor** that explains topics step by step, generates practice quizzes, provides study materials, and tracks learning progress — all in one app.  

---

## 🌟 Why QuLearn?  
Many students struggle with self-study and cannot afford private tutors.  
QuLearn solves this by offering:  

- 🤖 **AI Tutor** – Ask any question and get a step-by-step explanation  
- 📝 **Quiz Generator** – Practice with AI-generated quizzes  
- 📚 **Learning Materials** – Notes, PDFs, and extra resources  
- 📊 **Progress Tracking** – Visualize your performance with charts  
- 🔒 **Free vs Premium** – Affordable access to personalized learning  

---

## 🛠 Tech Stack  

### **Frontend (Flutter Web + Mobile)**
- Flutter (Material 3, Provider for state management)  
- Firebase Auth (login & signup)  
- HTTP for backend integration  
- Charts for progress visualization  

### **Backend (Python FastAPI)**
- FastAPI (REST API framework)  
- Hugging Face Transformers (AI explanations + quiz generation)  
- scikit-learn (analysis/classification)  
- PostgreSQL + SQLAlchemy (database)  
- JWT Authentication (secure login)
